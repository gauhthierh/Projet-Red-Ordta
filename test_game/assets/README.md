# Assets

La démo actuelle n'utilise aucun fichier externe : l'arène, les personnages et les barres de vie sont générés avec des primitives G3N.

Les futurs modèles, textures, sons et polices devront être rangés ici, par exemple :

```text
assets/
├── models/
├── textures/
├── audio/
└── fonts/
```
